# Self-hosted fonts

All three families are open-source and subset to Latin, Latin Extended, Greek, punctuation,
arrows, mathematical operators, box drawing and miscellaneous symbols (★ ✓ → ≥ …) with
`fontTools.subset` (see `scripts/subset_fonts.sh`). Full originals are in `src/`.

| Family | Use | Licence | Source |
|---|---|---|---|
| IBM Plex Sans | body text | OFL 1.1 (`LICENSE-IBMPlex.txt`) | https://github.com/IBM/plex |
| Source Serif 4 | headings | OFL 1.1 (`LICENSE-SourceSerif.txt`) | https://github.com/adobe-fonts/source-serif |
| JetBrains Mono | code | OFL 1.1 (`LICENSE-JetBrainsMono.txt`) | https://github.com/JetBrains/JetBrainsMono |

`@font-face` rules are generated by Quarto from `brand/*.yml` (typography → fonts → source: file).
