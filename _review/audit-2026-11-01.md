## 1. Fix first (high)

### Content

1. **Episode 2.5 quotes the wrong accuracy and confusion matrix.** `05-classification.qmd` lines 110, 190, 201 to 204 and the figure's alt text say 98.6% accuracy with TP 52, FN 1, FP 1, TN 89. The page's own executed output is accuracy 0.965 and confusion matrix `[[89, 1], [4, 49]]`, so 4 cancers are missed, not 1. Fix: 96.5%, TP 49, FN 4, FP 1, TN 89. Four missed cancers makes the "dangerous cell" point stronger.
2. **Episode 2.5 threshold claim is false.** Line 270 says a threshold of 0.1 "catches every malignant tumour". At 0.1 recall is 0.981 (one cancer missed); recall 1.0 needs 0.05, with 11 false positives. The alt text at line 367 also says "one or two more" false positives where the figure shows three more.
3. **Both student notebooks contain the answers.** `make_student_notebooks.py` stubs only code cells, so interpretive markdown is copied verbatim. Lab 2 student cells 21, 27, 33, 34 and 39 give the ridge result, "kNN is clearly best", the worst-ten analysis, the full conclusion and the extension numbers. Lab 1 cells 21, 25, 29, 33, 37 and 40 answer Tasks 4 to 9, including the model summary Task 9 asks the student to write. The raw first cell of both still reads "Lab N solutions" with `lab-solutions: true`. Fix: tag those cells `solutions-only` (split Lab 2 cell 21 so its "Task 6" heading survives) and rewrite the raw cell in the generator.
4. **The minimum Python version is wrong.** Episode 0.2 (lines 138, 151, 175, 188 to 195) and `scripts/check_env.py` say 3.10 or newer works. The pinned numpy 2.5.4 requires Python 3.12; pandas 3.1.0, scikit-learn 1.9.1 and ipykernel 7.4.0 require 3.11. `pip install -r requirements.txt` fails on 3.10 and 3.11. In addition, `check_env.py` prints ❌ for an old Python but does not count it as a problem, so it still says "All good" and exits 0. Fix: require 3.12 in the text and in the script, and count the failure.
5. **Penguin cells fail in Colab.** Episode 0.2 says every Part I cell runs in a fresh Colab notebook, but episodes 1.3 (line 45) and 1.4 (line 43) read `data/penguins.csv` with no fallback, which does not exist in Colab. ESOL already uses a local-file-then-URL pattern; penguins should do the same.
6. **Appendix A, Proposition 9 item 3 is false as stated.** "For any valid base, log is strictly increasing" fails for bases between 0 and 1, which Definition 16 allows. Fix: "for a base greater than 1 (in particular 10 and e)".
7. **Appendix A gives the wrong reason for the kNN flip.** Line 276 says the scaled nearest neighbour changes "because the Gentoo and Adelie bills are very different in depth". The Gentoo bill depth differs from both other species. The flip comes from flipper length and bill length: the Chinstrap's bill is almost exactly as long as the Gentoo's (46.5 vs 46.1 mm) and its flippers are closer (192 vs 211 mm, against 181 for the Adelie).

### Site

8. **The pager prints "userdata: 0000000000000000".** On 7 pages the Next or Previous card reads, for example, "userdata: 0000000000000000 Chapter 0 key points". It happens whenever the neighbour is a key-points page, a quiz or a chapter page. Pages: 0.3, Chapter 1 index, Lab 1, Chapter 2 checkpoint, Chapter 2 index, Lab 2, Chapter 3 index. Cause: `card()` in `_extensions/mm/episode.lua` tests `item.label and ...`; a JSON `null` label arrives as a truthy userdata. Fix: `type(item.label) == "string" and item.label ~= ""`.
9. **Sidebar and "On this page" slide under the header after scrolling.** On every page in both themes, once the page scrolls, both rails move to `top: 0` while the header stays visible (78 px tall in dark, 61 px in light), hiding "Part I: Foundations", the "On this page" title and the first contents entry. Cause: `.headroom--unpinned { transform: none !important; }` keeps the header, but Quarto's headroom script still moves the rails as if it had hidden. Fix: set `navbar: pinned: true` in `_quarto.yml` and remove the override.
10. **The default dark theme loses most of the type and spacing scale.** In dark mode the dark Bootstrap sheet loads after the light one and re-emits base rules with default variables. Measured, dark against light: navbar padding 8.5 px against 0 (header 78 against 61 px, so the active-tab underline floats 13 px above the rule), bold 700 against 600, table cell padding 8.5 against 11.9 px, inline-code padding, border radius, and the "On this page" title in sans instead of serif. Fix: move every non-colour `scss:defaults` value from `mm-light.scss` into `_tokens.scss` so both themes compile with them.
11. **Selected search result is unreadable in dark.** Light text on the light-blue accent, 1.8:1. Fix: give the selected item `var(--mm-surface-2)` with `var(--mm-text)`, or dark text on the accent.

### Appendix A and glossary

- **Theorem 1 proof is incomplete.** The 3 ⇒ 1 step builds B with AB = I but never shows BA = I, which Definition 3 requires. One line fixes it: A(BA − I) = 0, so every column of BA − I is 0 by item 3.
- **Bayes' theorem needs 0 < P(A) < 1.** The expansion of P(B) uses P(B | Aᶜ).
- **The biologist's bridge misstates the example.** "A screen that flags 2% actives": 2% is the prevalence; the assay flags 6.7%.
- **Glossary `normal-equation` contradicts Theorem 6 and episode 2.2.** It calls the closed-form solution the normal equation; both pages define it as the system XᵀXθ = Xᵀy. It also omits invertibility.
- **Glossary `recall` reads as 1.** "the fraction of true positives the model identifies" should be "of actual positives".
- **Notation clashes.** X is both the data matrix and a random variable; θ is both the parameter vector and an angle; the weights are w in one section and θ in another; Definition 7 writes the gradient as a row despite the column convention; Chapter 2 indexes the intercept as θ₀. Add a sentence to the notation table and use φ for the angle.
